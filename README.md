A fully 3d printable marble run that has a handcrank elevator incorporated into the design!

## Why I made it
I thought it would be a fun way to learn and develop my understanding of physics in CAD, I was able to learn a lot about the math behind friction and kinetic energy.

## How it works
I designed the tracks to have the most minimal design, this lets the marble have the least contact area with the track, decreasing the friction and increasing the potential speed from potential energy. The track is built with 3 floors, and has a hand crank elevator utilizing a lead screw vertical lift.

To Build the project, like most of my complicated projects, it's hard to explain how to assemble it as it's much easier for you to visually interact with the model through CAD.
